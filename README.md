Serverless auction microservice deployed on AWS. Exposes a REST API through API Gateway for creating auctions, listing them, fetching details, and placing bids. Data lives in DynamoDB with stage-isolated tables.

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/auction` | Create a new auction |
| GET | `/auctions` | List all auctions |
| GET | `/auction/{id}` | Get a single auction by ID |
| PATCH | `/auction/{id}/bid` | Place a bid (updates highest bid) |

Request validation uses JSON Schema definitions that also generate TypeScript types at compile time via `json-schema-to-ts`.

## Architecture

Each endpoint is its own Lambda function with a dedicated handler, schema, and Serverless config. Shared logic (DynamoDB operations, error handling) lives in the `services/` layer. Middleware processing (JSON body parsing, error normalization, event normalization) is handled by Middy.

```
src/
  functions/auction/
    createAuction/    Handler, schema, Serverless config
    getAuctions/
    getSingleAuction/
    placeBid/
  services/           DynamoDB operations (CRUD)
  libs/               Middy middleware wrapper, API Gateway helpers
  types/              Auction and Bid interfaces, status enum
  resources/          CloudFormation resource definitions (DynamoDB table)
  iam/                IAM role statements for DynamoDB access
serverless.ts         Service configuration (functions, resources, plugins)
```

## Deploy

Requires AWS credentials configured (profile `personal` by default):

```bash
npm install
npm run deploy:dev      # Deploy to dev stage
npm run deploy:prod     # Deploy to prod stage
npm run deploy:qa       # Deploy to QA stage
```

Single function deploys are also supported for faster iteration:

```bash
npm run deploy:fn       # Redeploy only the auction functions
```

## Tech Stack

- **Runtime:** Node.js 14 on AWS Lambda
- **API:** API Gateway REST API (auto-generated by Serverless)
- **Database:** DynamoDB (single table, stage-scoped naming)
- **Middleware:** Middy (JSON body parser, error handler, event normalizer)
- **Build:** esbuild via serverless-esbuild (bundled, source maps)
- **IaC:** Serverless Framework 3 with CloudFormation resources
- **Typing:** `json-schema-to-ts` for request validation + type generation
